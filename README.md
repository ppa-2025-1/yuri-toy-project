# yuri-toy-project
Toy Project da disciplina de PPA

## Execução do projeto
1. Abrir o terminal na raiz do projeto e executar ```docker-compose up -d``` para inicializar o RabbitMQ
2. Acesse ```http://localhost:15672``` para acessar o RabbitMQ 
   1. Usuário: guest
   2. Senha: guest

- Executar na raiz do projeto ```.gradlew.bat bootRun```
